# Chapter 3.5: PHP to PostgreSQL Direct Querying

[← Back to Index](./README.md)

---

## Overview

After Payload collections are created and MySQL data is migrated to PostgreSQL, the current PHP site has a simpler path than the previous Sanity approach: **query PostgreSQL directly** using standard PHP database extensions (PDO or mysqli). This eliminates the need to learn GraphQL or GROQ query languages.

This chapter explains how to adapt the existing PHP models to connect to and query the Neon PostgreSQL database.

---

## Why Direct PostgreSQL Access?

### Advantages Over GraphQL/GROQ
- **No new query language**: Use familiar SQL syntax
- **Native PHP support**: PDO and mysqli work out-of-the-box with PostgreSQL
- **Better performance**: Direct database queries eliminate API overhead
- **Simpler debugging**: Standard SQL queries are easier to inspect
- **Gradual migration**: Can switch models one-by-one using factory pattern

### When to Use Payload API vs Direct PostgreSQL

| Use Case | Approach | Reason |
|----------|----------|--------|
| **Read-only frontend** | Direct PostgreSQL | Better performance, simpler code |
| **Admin operations** | Payload Admin UI | Built-in validation, hooks, access control |
| **Content creation** | Payload API or Admin | Ensures data consistency and triggers hooks |
| **External integrations** | Payload REST/GraphQL API | Proper authentication and authorization |
| **High-volume reads** | Direct PostgreSQL | Lower latency, connection pooling |

### PDO Connection (Recommended)

**File:** `src/lib/Database.php`

```php
<?php

namespace YNotRadio\Lib;

use PDO;
use PDOException;

class Database {
    private static ?PDO $postgresConnection = null;
    private static ?PDO $mysqlConnection = null;

    /**
     * Get PostgreSQL connection using PDO
     */
    public static function getPostgres(): PDO {
        if (self::$postgresConnection === null) {
            try {
                $host = getenv('POSTGRES_HOST');
                $port = getenv('POSTGRES_PORT') ?: '5432';
                $dbname = getenv('POSTGRES_DATABASE');
                $user = getenv('POSTGRES_USER');
                $password = getenv('POSTGRES_PASSWORD');
                $sslmode = getenv('POSTGRES_SSL_MODE') ?: 'require';

                $dsn = "pgsql:host={$host};port={$port};dbname={$dbname};sslmode={$sslmode}";
                
                self::$postgresConnection = new PDO($dsn, $user, $password, [
                    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                    PDO::ATTR_EMULATE_PREPARES => false,
                ]);
            } catch (PDOException $e) {
                error_log("PostgreSQL connection failed: " . $e->getMessage());
                throw $e;
            }
        }
        
        return self::$postgresConnection;
    }

    /**
     * Get MySQL connection (legacy, for gradual migration)
     */
    public static function getMySQL(): PDO {
        if (self::$mysqlConnection === null) {
            try {
                $host = getenv('MYSQL_HOST');
                $dbname = getenv('MYSQL_DATABASE');
                $user = getenv('MYSQL_USER');
                $password = getenv('MYSQL_PASSWORD');

                $dsn = "mysql:host={$host};dbname={$dbname};charset=utf8mb4";
                
                self::$mysqlConnection = new PDO($dsn, $user, $password, [
                    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                    PDO::ATTR_EMULATE_PREPARES => false,
                ]);
            } catch (PDOException $e) {
                error_log("MySQL connection failed: " . $e->getMessage());
                throw $e;
            }
        }
        
        return self::$mysqlConnection;
    }
}
```

## PostgreSQL Model Implementation

### Creating PostgreSQL-Aware Models

**File:** `src/models/implementations/PostgresDeejay.php`

```php
<?php

namespace YNotRadio\Models\Implementations;

use YNotRadio\Models\Deejay;
use PDO;

class PostgresDeejay implements Deejay {
    private PDO $db;

    public function __construct(PDO $db) {
        $this->db = $db;
    }

    public function getById(int $id): ?array {
        $stmt = $this->db->prepare(
            "SELECT * FROM djs WHERE id = :id AND deleted_at IS NULL"
        );
        $stmt->execute(['id' => $id]);
        
        $data = $stmt->fetch();
        return $data ?: null;
    }

    public function getAll(int $limit = 64): array {
        $stmt = $this->db->prepare(
            "SELECT * FROM djs WHERE deleted_at IS NULL ORDER BY sort LIMIT :limit"
        );
        $stmt->bindValue(':limit', $limit, PDO::PARAM_INT);
        $stmt->execute();
        
        return $stmt->fetchAll();
    }

    public function getAllFlat(): array {
        return $this->getAll();
    }

    public function add(array $data): int {
        $stmt = $this->db->prepare(
            "INSERT INTO djs (name, show_name, on_air, bio, social_links, created_at, updated_at)
             VALUES (:name, :show_name, :on_air, :bio, :social_links, NOW(), NOW())
             RETURNING id"
        );
        
        $stmt->execute([
            'name' => $data['name'],
            'show_name' => $data['show_name'] ?? null,
            'on_air' => $data['on_air'] ?? true,
            'bio' => json_encode($data['bio'] ?? null),
            'social_links' => json_encode($data['social_links'] ?? []),
        ]);
        
        $result = $stmt->fetch();
        return $result['id'];
    }

    public function update(int $id, array $data): bool {
        $stmt = $this->db->prepare(
            "UPDATE djs 
             SET name = :name,
                 show_name = :show_name,
                 on_air = :on_air,
                 bio = :bio,
                 social_links = :social_links,
                 updated_at = NOW()
             WHERE id = :id AND deleted_at IS NULL"
        );
        
        return $stmt->execute([
            'id' => $id,
            'name' => $data['name'],
            'show_name' => $data['show_name'] ?? null,
            'on_air' => $data['on_air'] ?? true,
            'bio' => json_encode($data['bio'] ?? null),
            'social_links' => json_encode($data['social_links'] ?? []),
        ]);
    }

    public function delete(int $id): bool {
        // Soft delete
        $stmt = $this->db->prepare(
            "UPDATE djs SET deleted_at = NOW() WHERE id = :id"
        );
        
        return $stmt->execute(['id' => $id]);
    }

    public function getName(int $id): string {
        $dj = $this->getById($id);
        return $dj['name'] ?? '';
    }

    public function updateSortOrder(array $items): bool {
        $this->db->beginTransaction();
        
        try {
            $stmt = $this->db->prepare(
                "UPDATE djs SET sort = :sort WHERE id = :id"
            );
            
            foreach ($items as $index => $id) {
                $stmt->execute([
                    'id' => $id,
                    'sort' => $index + 1
                ]);
            }
            
            $this->db->commit();
            return true;
        } catch (\Exception $e) {
            $this->db->rollBack();
            throw $e;
        }
    }
}
```

## Factory Pattern Integration

Update the factory to support PostgreSQL implementation:

**File:** `src/models/DeejayFactory.php`

```php
<?php

namespace YNotRadio\Models;

require_once __DIR__ . '/FeatureManager.php';
require_once __DIR__ . '/Deejay.php';
require_once __DIR__ . '/implementations/SqlDeejay.php';
require_once __DIR__ . '/implementations/PostgresDeejay.php';

use YNotRadio\Models\FeatureManager;
use YNotRadio\Models\Implementations\SqlDeejay;
use YNotRadio\Models\Implementations\PostgresDeejay;

class DeejayFactory {
    public static function create($db) {
        // Check if PostgreSQL connection is available
        if (FeatureManager::isEnabled('use_postgres_deejays') && $db instanceof \PDO) {
            return new PostgresDeejay($db);
        }
        
        // Fall back to MySQL
        return new SqlDeejay($db);
    }
}
```

## PostgreSQL-Specific Features

### JSONB Queries

PostgreSQL's JSONB type allows efficient JSON querying:

```php
// Query DJs with specific social media
$stmt = $db->prepare(
    "SELECT * FROM djs 
     WHERE social_links->>'twitter' IS NOT NULL 
     AND deleted_at IS NULL"
);
$stmt->execute();
$djsWithTwitter = $stmt->fetchAll();

// Query artists by bio content
$stmt = $db->prepare(
    "SELECT * FROM artists 
     WHERE bio @> :search_json
     AND deleted_at IS NULL"
);
$stmt->execute(['search_json' => json_encode(['type' => 'doc'])]);
```

### Array Types

PostgreSQL supports native arrays:

```php
// Example: Tags as array
$stmt = $db->prepare(
    "SELECT * FROM songs 
     WHERE :tag = ANY(tags)
     AND deleted_at IS NULL"
);
$stmt->execute(['tag' => 'indie rock']);
```

### Full-Text Search

Use PostgreSQL's built-in full-text search:

```php
// Search artists by name or bio
$stmt = $db->prepare(
    "SELECT *, 
            ts_rank(to_tsvector('english', name || ' ' || coalesce(bio::text, '')), 
                    plainto_tsquery('english', :query)) AS rank
     FROM artists
     WHERE to_tsvector('english', name || ' ' || coalesce(bio::text, '')) 
           @@ plainto_tsquery('english', :query)
     AND deleted_at IS NULL
     ORDER BY rank DESC
     LIMIT 10"
);
$stmt->execute(['query' => 'indie rock']);
$results = $stmt->fetchAll();
```

### Window Functions

PostgreSQL window functions for analytics:

```php
// Get top songs with rankings
$stmt = $db->prepare(
    "SELECT 
        s.title,
        a.name as artist_name,
        COUNT(v.id) as vote_count,
        RANK() OVER (ORDER BY COUNT(v.id) DESC) as ranking
     FROM songs s
     INNER JOIN song_artists sa ON s.id = sa.song_id
     INNER JOIN artists a ON sa.artist_id = a.id
     LEFT JOIN top11_votes v ON s.id = v.song_id
     WHERE s.deleted_at IS NULL
     GROUP BY s.id, s.title, a.name
     ORDER BY vote_count DESC
     LIMIT 11"
);
$stmt->execute();
$topSongs = $stmt->fetchAll();
```

## Common Query Patterns

### Joining with Relationships

**Example: Get concerts with artist and venue details**

```php
$stmt = $db->prepare(
    "SELECT 
        c.id,
        c.date,
        c.ticket_url,
        a.name as artist_name,
        a.slug as artist_slug,
        v.name as venue_name,
        v.city as venue_city,
        m.url as artist_photo_url
     FROM concerts c
     INNER JOIN artists a ON c.artist_id = a.id
     INNER JOIN venues v ON c.venue_id = v.id
     LEFT JOIN media m ON a.photo_id = m.id
     WHERE c.date >= CURRENT_DATE
     AND c.deleted_at IS NULL
     ORDER BY c.date ASC
     LIMIT :limit"
);

$stmt->bindValue(':limit', 20, PDO::PARAM_INT);
$stmt->execute();
$upcomingConcerts = $stmt->fetchAll();
```

### Handling Rich Text (JSONB)

```php
// Extract plain text from TipTap JSON
$stmt = $db->prepare(
    "SELECT 
        id,
        name,
        bio->>'content' as bio_content
     FROM artists
     WHERE deleted_at IS NULL"
);
$stmt->execute();

// Process rich text in PHP if needed
foreach ($stmt->fetchAll() as $artist) {
    $bioJson = json_decode($artist['bio_content'], true);
    // Extract plain text from TipTap structure
    $plainText = extractPlainText($bioJson);
}

function extractPlainText($tiptapJson): string {
    if (!is_array($tiptapJson) || !isset($tiptapJson['content'])) {
        return '';
    }
    
    $text = '';
    foreach ($tiptapJson['content'] as $node) {
        if (isset($node['content'])) {
            foreach ($node['content'] as $textNode) {
                if (isset($textNode['text'])) {
                    $text .= $textNode['text'] . ' ';
                }
            }
        }
    }
    
    return trim($text);
}
```

## Migration Strategy

### Gradual Model Conversion

1. **Phase 1**: Add PostgreSQL implementation alongside MySQL
   - Create `PostgresDeejay`, `PostgresConcert`, etc.
   - Update factories to support feature flags
   - Test both implementations in parallel

2. **Phase 2**: Enable PostgreSQL per model with feature flags
   ```bash
   # .env
   FEATURE_POSTGRES_DEEJAYS=true
   FEATURE_POSTGRES_CONCERTS=false  # Still using MySQL
   ```

3. **Phase 3**: Validate and compare results
   ```php
   // src/lib/ValidationHelper.php
   public static function compareResults($mysqlModel, $postgresModel) {
       $mysqlData = $mysqlModel->getAll();
       $postgresData = $postgresModel->getAll();
       
       // Compare and log differences
       if (json_encode($mysqlData) !== json_encode($postgresData)) {
           error_log("Data mismatch detected!");
           // Log detailed differences
       }
   }
   ```

4. **Phase 4**: Full cutover
   - Enable all PostgreSQL feature flags
   - Monitor for 1 week
   - Remove MySQL models and database

## Error Handling

### PostgreSQL-Specific Errors

```php
try {
    $stmt = $db->prepare($query);
    $stmt->execute($params);
} catch (\PDOException $e) {
    // PostgreSQL error codes: https://www.postgresql.org/docs/current/errcodes-appendix.html
    
    if ($e->getCode() === '23505') {
        // Unique violation
        throw new \Exception("Record with this slug already exists");
    } elseif ($e->getCode() === '23503') {
        // Foreign key violation
        throw new \Exception("Referenced record does not exist");
    } else {
        error_log("Database error: " . $e->getMessage());
        throw $e;
    }
}
```

## Performance Optimization

### Prepared Statements (Already Shown)

Always use prepared statements for security and performance.

### Query Result Caching

```php
// src/lib/QueryCache.php
class QueryCache {
    private $cache = [];
    private $ttl = 300; // 5 minutes

    public function get(string $key) {
        if (isset($this->cache[$key])) {
            if (time() < $this->cache[$key]['expires']) {
                return $this->cache[$key]['data'];
            }
            unset($this->cache[$key]);
        }
        return null;
    }

    public function set(string $key, $data, int $ttl = null) {
        $this->cache[$key] = [
            'data' => $data,
            'expires' => time() + ($ttl ?? $this->ttl)
        ];
    }
}
```

PDO connections can be persistent:

```php
self::$postgresConnection = new PDO($dsn, $user, $password, [
    PDO::ATTR_PERSISTENT => true,  // Reuse connections
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    // ... other options
]);
```

## Testing

### Unit Tests for PostgreSQL Models

```php
// tests/models/PostgresDeejayTest.php
use PHPUnit\Framework\TestCase;

class PostgresDeejayTest extends TestCase {
    private $db;
    private $model;

        // Use test database
        $this->db = Database::getPostgres();
```

## Comparison: SQL vs GraphQL Approach

### Previous Sanity Approach (GraphQL/GROQ)

```php
// Had to learn GROQ query language
$query = '*[_type == "concert" && date >= $today] | order(date asc) {
  _id,
  date,
  "artist": artist->{name, slug},
  "venue": venue->{name, city}
}';

$params = ['today' => date('Y-m-d')];
$concerts = $sanityClient->fetch($query, $params);
```

### New PostgreSQL Approach (Direct SQL)

```php
// Standard SQL - no new language to learn
$stmt = $db->prepare(
    "SELECT 
        c.*,
        a.name as artist_name, a.slug as artist_slug,
        v.name as venue_name, v.city as venue_city
     FROM concerts c
     INNER JOIN artists a ON c.artist_id = a.id
     INNER JOIN venues v ON c.venue_id = v.id
     WHERE c.date >= :today
     AND c.deleted_at IS NULL
     ORDER BY c.date ASC"
);

$stmt->execute(['today' => date('Y-m-d')]);
$concerts = $stmt->fetchAll();
```

**Key Difference:** Direct PostgreSQL access uses standard SQL that PHP developers already know, eliminating the learning curve of GraphQL or GROQ.

## Security Considerations

### Always Use Prepared Statements

❌ **Never do this:**
```php
$query = "SELECT * FROM djs WHERE id = " . $_GET['id'];
$stmt = $db->query($query);  // SQL injection vulnerability!
```

✅ **Always do this:**
```php
$stmt = $db->prepare("SELECT * FROM djs WHERE id = :id");
$stmt->execute(['id' => $_GET['id']]);
```

### Read-Only Database User

For frontend queries, use a read-only database user:

```sql
-- Create read-only user for PHP frontend
CREATE ROLE php_readonly WITH LOGIN PASSWORD 'secure_password';
GRANT CONNECT ON DATABASE ynot_radio TO php_readonly;
GRANT USAGE ON SCHEMA public TO php_readonly;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO php_readonly;

-- Ensure future tables are also readable
ALTER DEFAULT PRIVILEGES IN SCHEMA public
GRANT SELECT ON TABLES TO php_readonly;
```
