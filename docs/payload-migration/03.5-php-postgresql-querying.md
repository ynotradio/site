# Chapter 3.5: PHP to PostgreSQL Direct Querying

[← Back to Index](./README.md)

## Overview

After Payload collections are created and data is migrated to PostgreSQL, PHP can query the database directly using PDO—no need to learn GraphQL or GROQ.

**When to use direct PostgreSQL:**

- Read-only frontend queries (better performance)
- High-volume reads (lower latency)

**When to use Payload API:**

- Admin operations (validation, hooks, access control)
- Content creation (data consistency)
- External integrations (authentication)

## PostgreSQL Connection Setup

```bash
# .env
POSTGRES_HOST=ep-example-123456.us-east-2.aws.neon.tech
POSTGRES_PORT=5432
POSTGRES_DATABASE=ynot_radio
POSTGRES_USER=ynot_admin
POSTGRES_PASSWORD=your_secure_password
POSTGRES_SSL_MODE=require
```

**PDO Connection** (`src/lib/Database.php`):

```php
<?php
namespace YNotRadio\Lib;

use PDO;

class Database {
    private static ?PDO $postgresConnection = null;

    public static function getPostgres(): PDO {
        if (self::$postgresConnection === null) {
            $dsn = sprintf(
                "pgsql:host=%s;port=%s;dbname=%s;sslmode=%s",
                getenv('POSTGRES_HOST'),
                getenv('POSTGRES_PORT') ?: '5432',
                getenv('POSTGRES_DATABASE'),
                getenv('POSTGRES_SSL_MODE') ?: 'require'
            );

            self::$postgresConnection = new PDO($dsn, getenv('POSTGRES_USER'), getenv('POSTGRES_PASSWORD'), [
                PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES => false,
            ]);
        }

        return self::$postgresConnection;
    }
}
```

## PostgreSQL Model Implementation

**Example:** `src/models/implementations/PostgresDeejay.php`

```php
<?php
namespace YNotRadio\Models\Implementations;

use YNotRadio\Models\Deejay;
use PDO;

class PostgresDeejay implements Deejay {
    private PDO $db;

    public function __construct(PDO $db) {
        $this->db = $db;
    }

    public function getById(int $id): ?array {
        $stmt = $this->db->prepare("SELECT * FROM djs WHERE id = :id AND deleted_at IS NULL");
        $stmt->execute(['id' => $id]);
        return $stmt->fetch() ?: null;
    }

    public function getAll(int $limit = 64): array {
        $stmt = $this->db->prepare("SELECT * FROM djs WHERE deleted_at IS NULL ORDER BY sort LIMIT :limit");
        $stmt->bindValue(':limit', $limit, PDO::PARAM_INT);
        $stmt->execute();
        return $stmt->fetchAll();
    }

    public function add(array $data): int {
        $stmt = $this->db->prepare(
            "INSERT INTO djs (name, show_name, on_air, bio, social_links)
             VALUES (:name, :show_name, :on_air, :bio, :social_links)
             RETURNING id"
        );
        $stmt->execute([
            'name' => $data['name'],
            'show_name' => $data['show_name'] ?? null,
            'on_air' => $data['on_air'] ?? true,
            'bio' => json_encode($data['bio'] ?? null),
            'social_links' => json_encode($data['social_links'] ?? []),
        ]);
        return $stmt->fetch()['id'];
    }

    public function update(int $id, array $data): bool {
        $stmt = $this->db->prepare(
            "UPDATE djs SET name = :name, show_name = :show_name, on_air = :on_air,
                    bio = :bio, social_links = :social_links, updated_at = NOW()
             WHERE id = :id AND deleted_at IS NULL"
        );
        return $stmt->execute([
            'id' => $id,
            'name' => $data['name'],
            'show_name' => $data['show_name'] ?? null,
            'on_air' => $data['on_air'] ?? true,
            'bio' => json_encode($data['bio'] ?? null),
            'social_links' => json_encode($data['social_links'] ?? []),
        ]);
    }

    public function delete(int $id): bool {
        $stmt = $this->db->prepare("UPDATE djs SET deleted_at = NOW() WHERE id = :id");
        return $stmt->execute(['id' => $id]);
    }
}
```

## PostgreSQL-Specific Features

### JSONB Queries

```php
// Query DJs with specific social media
$stmt = $db->prepare(
    "SELECT * FROM djs
     WHERE social_links->>'twitter' IS NOT NULL
     AND deleted_at IS NULL"
);
$stmt->execute();
```

### Full-Text Search

```php
// Search artists by name or bio
$stmt = $db->prepare(
    "SELECT *, ts_rank(to_tsvector('english', name), plainto_tsquery('english', :query)) AS rank
     FROM artists
     WHERE to_tsvector('english', name) @@ plainto_tsquery('english', :query)
     ORDER BY rank DESC
     LIMIT 10"
);
$stmt->execute(['query' => 'indie rock']);
```

### Window Functions

```php
// Get top songs with rankings
$stmt = $db->prepare(
    "SELECT s.title, a.name as artist_name, COUNT(v.id) as vote_count,
            RANK() OVER (ORDER BY COUNT(v.id) DESC) as ranking
     FROM songs s
     INNER JOIN song_artists sa ON s.id = sa.song_id
     INNER JOIN artists a ON sa.artist_id = a.id
     LEFT JOIN top11_votes v ON s.id = v.song_id
     WHERE s.deleted_at IS NULL
     GROUP BY s.id, s.title, a.name
     ORDER BY vote_count DESC
     LIMIT 11"
);
$stmt->execute();
```

## Common Query Patterns

```php
// Get concerts with artist and venue details
$stmt = $db->prepare(
    "SELECT c.*, a.name as artist_name, v.name as venue_name, v.city as venue_city
     FROM concerts c
     INNER JOIN artists a ON c.artist_id = a.id
     INNER JOIN venues v ON c.venue_id = v.id
     WHERE c.date >= CURRENT_DATE AND c.deleted_at IS NULL
     ORDER BY c.date ASC
     LIMIT :limit"
);
$stmt->bindValue(':limit', 20, PDO::PARAM_INT);
$stmt->execute();
```

## Current Model Strategy

Migrated models use PostgreSQL implementations directly. The old feature-flag rollout and MySQL fallback branches are retired for migrated content.

1. Keep PHP read models read-only.
2. Edit migrated content in Payload.
3. Query Payload/Postgres tables directly from PHP where the legacy public site still renders the page.
4. Leave Top 11 and Year End Poll/Staff Picks on legacy MySQL until their Payload workflows are ready.

## Error Handling

```php
try {
    $stmt = $db->prepare($query);
    $stmt->execute($params);
} catch (\PDOException $e) {
    if ($e->getCode() === '23505') {
        throw new \Exception("Record with this slug already exists");
    } elseif ($e->getCode() === '23503') {
        throw new \Exception("Referenced record does not exist");
    }
    error_log("Database error: " . $e->getMessage());
    throw $e;
}
```

## Security Considerations

**Always use prepared statements:**

```php
// ✅ Correct
$stmt = $db->prepare("SELECT * FROM djs WHERE id = :id");
$stmt->execute(['id' => $_GET['id']]);

// ❌ Never do this
$query = "SELECT * FROM djs WHERE id = " . $_GET['id'];  // SQL injection!
```

**Use read-only database user for frontend:**

```sql
CREATE ROLE php_readonly WITH LOGIN PASSWORD 'secure_password';
GRANT CONNECT ON DATABASE ynot_radio TO php_readonly;
GRANT USAGE ON SCHEMA public TO php_readonly;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO php_readonly;
```
